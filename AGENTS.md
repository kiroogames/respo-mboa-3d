# Consignes de collaboration pour ce projet

## Fonctionnalités décrites dans les documents Markdown

Instruction explicite de l’utilisateur du 23 octobre 2026 : avant d’ajouter une fonctionnalité issue des documents Markdown d’amélioration du jeu, la présenter pour que nous la validions ensemble.

- Lire, analyser et comparer ces documents avec le jeu existant est autorisé.
- Avant de développer une fonctionnalité issue de ces documents, indiquer le document et la section concernés, le comportement proposé et son impact sur le jeu actuel (notamment temps, économie, sauvegardes et interface).
- Attendre une validation explicite de l’utilisateur sur cette proposition avant son implémentation. L’absence de réponse ne vaut pas accord.
- Une validation concerne la fonctionnalité et le périmètre discutés ; elle n’autorise pas automatiquement les autres fonctionnalités des documents.
- Les questions ouvertes ou contradictions des documents doivent être signalées, pas tranchées silencieusement.
- La présence d’une règle dans un document ne justifie pas de modifier rétroactivement le jeu sans cette validation.
